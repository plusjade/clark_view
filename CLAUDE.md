# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Claude specific guidence

Your prose must express your point simply and briefly. Say what you mean up front and once.

* Omit extended explanation and justifications
* Omit counter-examples: "its x, not y or z"
* Omit explaining and self-evident functionality
* Omit restatements.
* Omit history-of-record prose for future agents to recreate history. Instead: a single blurb of net-new functionality with reasoning only when not self-evident or an intentional architecture guide.

Triggers:
* When summarizing prose for future agents, STOP. Instead, document features as is instructed by the code guidelines, nothing more.
